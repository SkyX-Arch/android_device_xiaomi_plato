# Security Policy

## Supported Versions

This repository is actively maintained for the latest development branch.

Security fixes are generally applied to the current branch only. Older revisions may not receive updates.

## Reporting a Vulnerability

If you believe you have found a security vulnerability related to this repository, please report it responsibly.

Please include:

* A clear description of the issue
* Steps to reproduce the problem
* Potential impact
* Relevant logs or proof-of-concept, if available

Avoid publicly disclosing security vulnerabilities before they have been reviewed and addressed.

## Scope

This policy applies only to issues directly related to this repository.

The following are generally considered out of scope:

* Vulnerabilities originating from proprietary vendor components
* Issues in third-party software not maintained in this repository
* Android platform vulnerabilities already tracked upstream
* Hardware or firmware vulnerabilities outside the repository's control

## Response

This project is maintained in spare time as a hobby project.

While all reports are appreciated, response times may vary and fixes cannot be guaranteed within a specific timeframe.

## Disclosure

After a vulnerability has been reviewed and, if applicable, fixed, public disclosure may take place through the repository's issue tracker, commit history, or release notes.
