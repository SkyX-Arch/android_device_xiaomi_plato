# Xiaomi 12T (plato)

Device tree for Xiaomi 12T (plato).

The Xiaomi 12T is a MediaTek MT6895-based smartphone released by Xiaomi in October 2022.

## Device Information

## Device Specifications

| Spec | Details |
|------|---------|
| SoC | MediaTek Dimensity 8100 Ultra (MT6895) |
| CPU | Octa-core (4x Cortex-A78 @ 2.85 GHz & 4x Cortex-A55 @ 2.0 GHz) |
| GPU | Mali-G610 MC6 |
| Memory | 8GB LPDDR5 |
| Storage | 128/256GB UFS 3.1 |
| Battery | 5000 mAh |
| Display | 6.67" AMOLED, 1220×2712, 120Hz |
| Rear Camera | 108 MP + 8 MP + 2 MP |
| Front Camera | 20 MP |

## Purpose

This repository contains the device-specific configuration required to build Android-based ROMs for the Xiaomi 12T (plato).

## Supported ROMs

This device tree is currently used for:

* [crDroid Android 16](https://github.com/SkyX-Arch/crdroid-ota)

## Status

* Android 16
* SELinux Enforcing
* OTA Support
* User Builds
* Release Keys Support
